# 🖼️ Image Background Change Effect

An interactive **before-and-after image reveal effect** built with **HTML, CSS, and JavaScript**.

Drag the **vertical comparison pointer** across the image to smoothly reveal the original image and its **transparent/background-removed version**.

---

## ✨ Features

- 🖱️ **Interactive draggable comparison pointer**
- 🔄 **Smooth before-and-after image reveal**
- 🎨 **Original image appears as the pointer moves**
- 🪄 **Transparent/background-removed image is revealed on the other side**
- 📱 **Responsive design**
- ⚡ **Built with pure HTML, CSS, and JavaScript**
- 🚫 **No external libraries required**

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**

---

## 📸 How It Works

The project uses **two versions of the same image**:

1. 🖼️ A **normal image** with its original background.
2. ✨ A **background-removed transparent image**.

A **draggable vertical divider** controls how much of each image is visible.

As you drag the pointer from left to right, the image smoothly changes between the **original background** and the **transparent/background-removed version**.
